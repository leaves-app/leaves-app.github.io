基本

個人情報やセキュリティが気になります

Aicaは開発者のサーバーを使用せず、iPhoneのカレンダーと連携して動作します。AIにはApple Foundation Modelsを利用し、音声認識も含めて端末内で処理するため、予定の内容や音声が外部へ送信されることはありません。独自のアカウント登録もありません。

なお、無料版では広告配信のため、Google AdMobが端末情報や広告識別子などを取得する場合があります。詳しくはプライバシーポリシーをご確認ください。

どの端末で使えますか

iOS 26以降のiPhone、iPadOS 26以降のiPadでお使いいただけます。iPadの横向きなど広い画面では、カレンダーと選んだ日の予定を左右に並べて表示します。

AI機能の利用には、Apple Intelligenceに対応した端末と設定が必要です。対応していない端末でも、入力欄がキーワード検索になるほかは、カレンダーとしてすべての機能をお使いいただけます。

GoogleカレンダーやOutlookの予定も表示できますか

Aicaは、iPhoneの「カレンダー」に登録されている予定を表示します。iPhoneの設定 → アプリ → カレンダー → カレンダーアカウントでGoogleなどのアカウントを追加すると、Aicaにも表示されるようになります。

表示するカレンダーや予定の保存先を変えたい

設定 → カレンダー →「カレンダー設定」から、表示するカレンダー、新しい予定の保存先、カレンダーの名前と色を変更できます。AIに「仕事カレンダーを非表示にして」のように頼むこともできます。

チュートリアルをもう一度見たい

設定 → サポート →「チュートリアルを見る」から、いつでも見返せます。

機種変更・再インストールでデータは引き継がれますか

予定はiPhoneのカレンダーに保存されているため、カレンダーの同期設定（iCloudなど）に従って引き継がれます。外観などの主な設定、植物、ギャラリーの記録は、同じApple AccountでiCloudにサインインしていれば自動的に引き継がれます。

操作履歴、背景画像、アイコンと植物の画像、通知の設定、表示するカレンダーの選択は引き継がれないため、新しい端末で設定し直してください。プレミアムの購入についてはこちらをご覧ください。

AIでの操作

AIに何を頼めますか

入力欄に入力するか、マイクで話しかけると、次のようなことができます。

  • 予定の追加：「明日15時に歯医者」「毎週月曜9時にジム」
  • 予定の変更：「会議を1時間後ろにずらして」
  • 予定の削除：「明日のランチを削除」
  • 予定の検索：「来週人と会う約束ある？」「次の歯医者いつ？」
  • 設定の変更：「ダークモードにして」「毎朝8時に予定一覧を通知して」
  • 画面の移動：「通知設定を開いて」「12月3日を表示」
  • 使い方の質問：「予定の取り消し方は？」

追加・変更・削除・設定の変更は、反映する前に必ず確認が表示されます。

AIによる操作がうまくいきません

端末内で動作するAIの性能には現時点で限界があり、うまく動作しない場合があります。「明日の15時から歯医者を1時間」のように、日付・時刻・内容を具体的に指示してみてください。

AIが使えない場合は、端末がApple Intelligenceに対応しているか、iPhoneの設定でApple Intelligenceがオンになっているかをご確認ください。

AIを使わずに使いたい

設定 → 機能の「AIを利用する」をオフにすると、入力欄がキーワード検索になります。今日から1年先までの予定を、予定名や詳細に含まれる言葉で探せます。予定の追加は＋ボタンから行えます。

音声入力が使えません

iPhoneの設定 → アプリ → Aicaで、マイクと音声認識を許可してください。話し終えて約2秒たつと自動で入力を終えて処理します。音声は端末内で認識され、外部へ送信されません。音声入力が使えない場合も、文字入力で同じ操作ができます。

操作を取り消したい

入力欄の上に表示される操作履歴のカードを左にスワイプすると、元に戻せます。AIや手動で行った予定の追加・変更・削除と、AIで変えた設定が対象です。取り消した後も履歴は残ります。

繰り返し予定をAIで削除できません

繰り返し予定は「この回だけ」か「すべての回」かを選ぶ必要があるため、AIでは削除しません。予定カードをタップし、iPhone標準の編集画面から範囲を選んで削除してください。

操作履歴の表示件数を変えたい

設定 → カレンダーから、3〜50件の範囲で変更できます。履歴は最大50件まで保存されます。表示件数を多くすると、動作が重くなる場合があります。

カレンダー・表示

表示を切り替えたい
  • タイムラインと一覧：予定の右上のアイコンで切り替えます。
  • 月・週・日：カレンダー上部の切り替えボタンをタップするか、その周辺を横にスワイプします。
  • 月表示の簡易・詳細：右上のアイコンで、各日の予定名まで表示する詳細表示に切り替えられます。

日付の表示をタップすると、カレンダーから日付を選んで移動できます。

予定の時間をドラッグで変えたい

タイムラインの予定カードを長押しすると、そのままドラッグして時間を移動できます。カードの上端・下端の中央を長押ししてドラッグすると、長さを変えられます（15分単位）。

誤って動かしてしまうのが心配な場合は、設定 → カレンダーの「ドラッグでの変更を確認」をオンにしてください。終日予定と繰り返し予定は、タップして編集画面から変更します。

夜遅くの予定が見づらい（日付の区切りを変えたい）

設定 → カレンダーで、タイムラインの開始時刻を0〜23時から選べます。たとえば6時にすると、6時から翌朝6時までを1日として表示します。

起動したらカレンダーを表示したい

設定 → 機能の「起動時にカレンダーを開く」をオンにすると、カレンダーのタブから始まります。

外観

見た目を変えたい

設定 → 外観から、次の項目を変更できます。すべて無料でご利用いただけます。

  • テンプレート（おすすめ・マイテンプレート・月ごとの自動切り替え）
  • フォント・文字サイズ・文字色
  • テーマ（ライト・ダーク・端末と同期）
  • リキッドグラスの種類と透過度、予定の色の濃さ
  • 背景色、各部の色、写真の背景画像
  • アイコンと植物の画像
月が変わったら見た目が変わりました

テンプレートの「自動切り替え」が「月ごと」になっていると、月が変わってアプリを開いたときに、その月のテンプレートに切り替わります（新しくインストールした場合は、はじめからオンになっています）。

切り替えたくない場合は、設定 → 外観の「自動切り替え」をオフにするか、お好きなテンプレートを選んでください。各月のテンプレートを、保存したマイテンプレートに変えることもできます。

今の見た目を保存しておきたい

設定 → 外観の「マイテンプレート」の列にある「現在の外観を保存」から、名前を付けて保存できます（最大20件）。長押しすると、上書き・名前の変更・削除ができます。

アイコンや植物を好きな画像にしたい

設定 → 外観 →「アイコンと植物」から、タブや入力欄のアイコン、植物（芽・若葉・各月の木）を、写真から選んだ画像に置き換えられます。いつでも標準の画像に戻せます。

通知・ウィジェット

通知やバッジを設定したい

設定 → 通知から、次の項目を設定できます。

  • 予定の通知：各予定に設定した通知の時刻に届きます
  • 毎日の予定一覧：指定した時刻に、当日または翌日の予定をまとめて通知します
  • バッジ：アプリアイコンに今日の予定の件数を表示します
通知が届かない・二重に届きます

届かない場合は、iPhoneの設定 → 通知 → Aicaで通知が許可されているかご確認ください。長い間アプリを開いていない場合や、ほかのアプリで予定を変更した直後は、通知が最新になっていないことがあります。アプリを一度開くと更新されます。

二重に届く場合は、iPhone標準のカレンダーからも同じ予定の通知が届いています。どちらか一方の通知をオフにしてください。

ウィジェットやライブアクティビティを使いたい

ホーム画面やロック画面を長押しして、ウィジェットの追加から「Aica」を選んでください。「次の予定」「タイムライン」「カレンダー」「Aicaに話しかける」があります。コントロールセンターやアクションボタンに、音声入力・文字入力を開くコントロールを割り当てることもできます。

ライブアクティビティは、設定 → 通知からオン・オフや、何分前の予定から表示するかを変更できます。

ライブアクティビティが表示されません

Aicaはサーバーを使わないため、ライブアクティビティを始められるのはアプリを開いたときに限られます。予定が近づいたらアプリを一度開いてください。終日予定と12時間を超える予定は対象外です。予定の終了後も、次にアプリを開くまで表示が残ることがあります。

表示されない場合は、iPhoneの設定 → アプリ → Aica →「ライブアクティビティ」がオンになっているかご確認ください。iPadでは利用できません。

楽しむための工夫

変な演出が発生しました

アプリを楽しむための工夫です。

工夫はいくつありますか

たくさんあります。アップデートで随時追加されます。

演出が邪魔です

設定 → 機能の「カレンダーモード」をオンにすると、ただのカレンダーアプリになります。

植物が成長しません

毎日アプリを起動して、植物を観察してください。

アイカちゃんに勝てません

アイカちゃんは1級相当（開発者基準）の実力があります。鍛錬してください。

見つけた隠し機能や独り言はどこで見られますか

設定 → ギャラリーから閲覧できます（無料でご利用いただけます）。まだ見つけていないものも、グレーで載っています。

誕生日を設定するとどうなりますか

誕生日にアプリを開くと、Aicaがお祝いします。設定 → 機能 →「誕生日」から設定できます。誕生日は端末の中だけに保存されます。

プラン・お支払い

プレミアムでは何ができますか

広告が表示されなくなります。外観のカスタマイズ、操作履歴、ギャラリーなど、ほかの機能はすべて無料でお使いいただけます。料金は月額200円（初回7日間の無料体験あり。対象となる方のみ）または買い切り1,500円です。

サブスクリプションを解約したい

iPhoneの「設定」→ お名前 →「サブスクリプション」から解約できます。アプリの設定 → プレミアムプランの「サブスクリプションを管理」からも開けます。アプリを削除しただけでは解約されません。詳しくはアプリ内課金についてをご確認ください。

機種変更したら購入が反映されていません

購入時と同じApple Accountでサインインし、アプリの設定 → プレミアムプランから「購入を復元」を行ってください。

返金してほしい

決済はAppleが行っているため、開発者から直接返金することはできません。Appleの「問題を報告する」ページからリクエストしてください。

「開発者を応援」とは何ですか

Aicaを気に入っていただけた方が、開発を応援するための購入（500円）です。設定 → プレミアムプランから何度でも購入できますが、機能の追加や広告の非表示などの特典はありません。

広告のトラッキングや同意の設定を変えたい

トラッキングの許可は、iPhoneの設定 → プライバシーとセキュリティ → トラッキングから変更できます。許可しなくても、アプリの機能は制限されません。同意が必要な地域では、アプリの設定 → プレミアムプランから広告のプライバシー設定を変更できます。
